## 📜 Sobre Mí

Soy un desarrollador apasionado por crear soluciones digitales que combinen una estética impecable con funcionalidad robusta. Me encanta experimentar con tecnologías emergentes, desde la automatización con IA hasta el desarrollo de ecosistemas en Minecraft. Creo que el código bien escrito puede cambiar la forma en que las personas interactúan con el mundo digital.

- 🔭 Actualmente trabajando en proyectos de **IA y Automatización**.
- 🌱 Aprendiendo constantemente sobre **Full-Stack Development** (TypeScript, Supabase).
- 🎮 Apasionado por el **desarrollo de servidores y plugins para Minecraft** con Kotlin.
- 💬 Pregúntame sobre **TypeScript, Kotlin, Node.js o arquitecturas backend**.
- ⚡ Fun fact: Me encanta optimizar flujos de trabajo — si algo se puede automatizar, lo automatizo.

## 💡 Filosofía de Desarrollo

> *"El mejor código es el que no necesitas escribir dos veces. Automatiza primero, optimiza después."*

- **Claridad sobre complejidad** — El código que se lee fácil, se mantiene fácil.
- **Estética + funcionalidad** — Las buenas interfaces no tienen por qué sacrificar ninguna de las dos.
- **Aprendizaje continuo** — El campo evoluciona rápido; la curiosidad es la herramienta más importante.
